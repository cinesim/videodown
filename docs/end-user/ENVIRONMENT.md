# Environment

| Name                          | Description                                                 |
| ----------------------------- | ----------------------------------------------------------- |
| `VIDEODOWN_DEBUG`             | Enable debug mode.                                          |
| `VIDEODOWN_DEBUG_KEYBOARD`    | Print more keyboard information when debug mode is enabled. |
| `VIDEODOWN_ERROR_INTERACTION` | Never show the error dialog to report bugs.                 |
| `VIDEODOWN_PANDOC`            | Overwrite the pandoc path.                                  |

## Development

| Name                      | Description                                                  |
| ------------------------- | ------------------------------------------------------------ |
| `VIDEODOWN_EXIT_ON_ERROR` | Exit on the first error or exception that occurs.            |
| `VIDEODOWN_IS_STABLE`     | **Please don't use this!** Used to identify stable releases. |
